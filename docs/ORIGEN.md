# Procedencia del código

Proyecto académico de Álgebra Lineal (Ingeniería en Sistemas, UPDS). Implementación en Python desarrollada por Armando H. Mendoza.

- `legacy/`: scripts experimentales de la versión académica original, conservados para referencia.
- `src/vision_matrices.py`: módulo matemático de la versión original, conservado.
- `src/detector.py`, `src/calibracion.py` y `main.py`: refactorización posterior, con enfoque exclusivo en detección A/B, calibración y diagnóstico.
- `data/`: parámetros históricos de escena. Las nuevas calibraciones se almacenan aparte en `calibracion_usuario/`, excluida de Git.

Este repositorio no incluye Arduino ni controles físicos. El código original se preserva en su versión de referencia para facilitar la trazabilidad.
